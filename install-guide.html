题库安装引导

解压文件 → 安装环境 → 连接 API → 开始使用

这是源码安装包，首次安装需要联网下载依赖。Windows 尚待实机验收；不需要安装 Codex。

01 准备软件

Windows 10/11，64 位。先安装下面的软件，再关闭并重新打开脚本窗口。

  • Python 3.11 x64：保留 Python Launcher，勾选添加到 PATH。
  • Node.js LTS：22.12 或更新版本，保留 npm。
  • OpenCode CLI：已有可运行的命令行版本无需重装。
  • LibreOffice：用于部分旧 Word 公式和组合图。

02 安装题库

在解压后的文件夹双击 01-install.cmd，确认后等待“安装完成”。不要在压缩包中直接运行。

03 配置自己的 API

双击 02-setup-api.cmd，按提示登录 OpenCode、选择已适配模型。已有登录可跳过登录步骤。

连接测试经你同意才发送一次简短请求，可能产生少量费用。失败不会自动重试或覆盖原配置。

04 开始使用

双击 03-start.cmd，启动完成后自动打开浏览器。保留窗口，停止时按 Ctrl+C。

首次打开是空题库。先上传一页带题图的样例，检查公式、图片和表格，再批量导入。

打不开 GitHub 时，可由朋友转发完整 ZIP。安装仍需网络；没有自动更新。数据和 API 配置保存在本机。

详细排错、macOS 安装与数据说明见同目录 INSTALL.md。本项目不是 OpenCode 官方产品，第三方声明见 THIRD_PARTY_NOTICES.md。

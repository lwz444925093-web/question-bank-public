# Question Bank · 教师题库

本地运行的数学、物理题库工具，支持材料导入、题目审查、可编辑题目与公式、分类树、试卷编排及 Word 导出。

这是从正式服务整理出的公开源码快照，不含原仓库的提交历史，也不含个人题库、试卷、讲义、真实题目测试样例、密钥、运行记录或未发布的测试版改动。文件专属的历史识别补丁登记表已清空。

## 安装

当前发布针对 macOS 本地运行。Windows 适配尚未进入正式版，此仓库不是经过 Windows 验收的安装包。

需要 Python 3.11、兼容 Vite 8 的 Node.js（22.12+），以及所选模型服务需要的 OpenCode CLI 或 Codex CLI。部分 Word 旧公式、组合图需要 LibreOffice。API 账户与费用由使用者自行配置和承担。

```sh
sh install.sh
sh start.sh
```

在浏览器打开 http://127.0.0.1:8765/ 。试卷放入 `materials/`，也可从网页上传。首次启动会创建本机空数据库。在设置中配置 AI 服务；安装包不提供模型账户或密钥。若需自定义导入提供者，可参考 `config.example.json` 创建本机 `config.json`。

可通过 `QUESTION_BANK_DATA`、`QUESTION_BANK_MATERIALS_DIR` 和 `QUESTION_BANK_PORT` 指定数据目录、材料目录和端口。建议使用绝对路径。默认只监听本机；未经过公网服务安全验收，请勿直接暴露到互联网。

## 数据与更新

本机数据库、上传材料、导出文件和 API 配置不会随此仓库发布。向 AI 服务发起识别或生成请求时，对应题目文字和必要图片会发送给所配置的模型服务。

仅在维护者明确发布时手动上传正式源码，没有自动同步或自动更新。保留本机 `data/`、`materials/` 和私人配置；更新程序前自行备份。此前私有测试版的 Windows 安装引导不适用于本版本。
